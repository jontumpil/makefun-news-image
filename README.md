A newspaper front page that sums up the world news of Friday 20 November 2026 in one image: the first Trump–Xi–Putin summit in Shenzhen, the World Court's genocide verdict on Myanmar, the missile strike on Kyiv, the AI-driven market sell-off, the Houthi strike on Riyadh, the COP31 fossil-fuel row and Kenya's Ebola all-clear. The image (entry.png) is drawn programmatically by compose_image.py from that day's reporting; main.py writes it to /output/entry.png, byte for byte, on every run.

## Run it

```sh
python3 main.py
```
